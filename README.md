# 🎈 Pipi Birthday Wish Project

Welcome to the Birthday Wish project workspace! The core application files and website code are located inside the `birthday-wish` directory.

---

## 🚀 Quick Start Guide

### Step 1: Open your terminal and go to the project folder
```bash
cd birthday-wish
```

### Step 2: Install dependencies
```bash
npm install
```

### Step 3: Run the project locally
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to see the birthday countdown and 3D wish pages!
